# Security Policy

## Supported Versions

Only the latest major release of the YOLO DevOps Platform is supported with security updates.

| Version | Supported |
| ------- | --------- |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:       |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to security@yolo-app.local. All security vulnerabilities will be promptly addressed.

Please do not open a public GitHub issue for security vulnerabilities.
